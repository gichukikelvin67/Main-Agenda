H1 M-Pesa Business POS – Frontend

A modern Point of Sale (POS) frontend built with Next.js and TypeScript for managing business products, customers, sales, transactions, and M-Pesa payments.

H1 Technologies

* Next.js
* TypeScript
* React
* Tailwind CSS
* Lucide React
* Vercel

H1 Features

  Business dashboard
  Product management
   Point of Sale system
   Customer management
   Sales management
   M-Pesa payment integration
   Transaction tracking
   Product search and categories
   Responsive design



H2 Deployment

The frontend is deployed on Vercel.

The application connects to the backend through the `NEXT_PUBLIC_API_URL` environment variable.


H2 Project Status

   Frontend completed
   Product management connected to backend
   POS system implemented
   Backend connected
   Deployed to Vercel
   M-Pesa STK Push final testing pending
